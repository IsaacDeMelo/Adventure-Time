# Ficha de Ooo — RPG de Hora de Aventura

Site de ficha de personagem para o RPG de Hora de Aventura na Terra de Ooo.
Página do RPG: https://honor-rating.onrender.com/rpg/adventure-time

## O que tem

- **Minha Ficha** em 6 passos: Identidade, Aparência, Atributos, Poderes, Mochila e Estudo.
- **Escrever Cena**: gera o cabeçalho `#iniciarcena` para o WhatsApp.
- **Rolar Dados**: 1d20, 1d40, 1d100, 1d5, estudo semanal e 2d6.
- **Regras**: manual de bolso (combate, estamina, up, popularidade, NPCs, família).
- **Nerfador**: ajusta habilidades e armas apelonas às regras de Nível 1.
- **Mandar no Zap**: exporta a ficha em 3 formatos.
- **Exportar / Importar**: leva a ficha para outro navegador por código ou arquivo `.json`.

## Como usar

É um único arquivo HTML, sem instalação e sem servidor. Abra o `index.html` no navegador
ou publique a pasta em qualquer hospedagem de site estático (GitHub Pages, Netlify, Render…).

A ficha fica salva no navegador de quem usa.

Para a prévia do link (WhatsApp/Discord) funcionar depois de publicar, troque
`img/preview.jpg` pelo endereço completo nas tags `og:image` e `twitter:image` do `index.html`.
